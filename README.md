# Everlight 长明 · RC6 Beta 14

面向 AI 的独立记忆系统：十二库、历史导入、精准召回、CRSI、自然联想、梦境整理、人物关系、任务与备份更新。**个人非商业公开测试候选，非生产版，非开源许可。**

当前发行版本：`0.1.0-beta.14`（核心包 `9.0.0-beta.14`，面板 `0.1.0-beta.14`，构建名 `RC6-J12-Beta14`）。

## 这一版（Beta 14，A–E 累计）

- **历史原话直接归档**，无需模型；一次导入授权。
- 普通历史记忆**默认单轮批量语义分类 + 本地校验**，取消默认的二次独立模型复核（严格复核仍可选）。日常修订与梦境治理门禁不变。
- 已符合 D9 写入合同的 AI 旧笔记可**零模型调用直入**；混合分流、可插拔 embedding、仅向量候选标签。
- 扩大 S04／S05／S06／S08／S11／S12 的自动提交范围；S03／S07／S09 等冲突任务、身份与关系**不得**自动激活；S02／S10 由运行生成。
- 跨文件精确原话去重、同证据提案去重、跨批次向量缓存、授权历史原话向量索引、CRSI 无有效命中时的语义补查。
- 免费导入预览、可选持久金额预算、请求前预留与结算、导入进度与费用面板。
- 历史语义补查**默认关闭**，须独立授权与真实校准，仅允许可信私有网关。

## 从 Beta 13 升级（**先读这一节**）

**Beta 13 的旧解包器遗漏了 `LICENSE.txt` 白名单**，所以装着 Beta 13 的用户**不能直接点旧版更新按钮**升级。第一次升级必须经过可信验签的**新版解包器桥接**：先用本版发行包内的解包与校验流程完成一次桥接，之后由新版自身的更新机制接管。

升级前请备份；升级过程中暂停所有写入者。升级与回滚流程以发行包内 `source/发行与更新.md` 为准。

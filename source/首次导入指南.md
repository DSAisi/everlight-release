# 首次历史导入 · Beta 03

> Beta 09 增量研发预览：梦境宿主邀请与 AI 自选分类见 `做梦与宿主接入.md`。八大内部认知模块继续隔离。未完成其他 P0 和正式发行联调，不作为最终公开发行包。下文 Beta 08 范围约束继续生效。

只在本包的独立单人试用库中使用。先备份自己的数据，使用有权处理且非敏感的测试记录，排除密钥、私密资料及未经授权的第三方信息。普通 S01 是明文原话，不是夜契加密库。本包默认不将旧原话自动注入模型。

## A. 一次确认归档全部原话（不需要模型）
1. 先按主 README 初始化并启动试用服务。另开一个终端，进入本包根目录。
2. 将 `converter/config.example.json` 复制为 `converter/config.json`。填写 input（相对 config 文件的路径）、workDir（新目录）、fieldMap。`scope` 保持 `personal`；`strictCore` 保持 true。支持 JSONL、JSON、TXT、CSV 及 GZ，最多 100,000 条。字段映射必须匹配自己的导出格式，检查 actor、时间、会话和消息 ID。
3. 如果仅归档，不启用任何外部处理。将 transport.type 设为 mock；若还要真实分类，请在 prepare 之前完成 B 的配置，否则用新 workDir 重新准备。

```sh
node converter/src/cli.mjs prepare --config converter/config.json
npm run beta:import -- --config converter/config.json --confirm-history
```

归档调用本机真实 source API，写入 S01，保留原话、来源、原始时间及历史标记。整份文件预检、哈希、数量校验；同一准备文件重复执行不会增加副本。中途中断可以重跑；已写入的原话不会自动回滚。改变原文件/顺序不是同一批次，暂未支持跨文件重复来源自动合并。S01 可在面板原始记录和字面检索中查看，不能直接视作已确认事实，也不默认注入模型。结果见 workDir/bootstrap-report.json。

## B. 批量语义分类及候选关联（可选，外部请求可能收费）
在 prepare 之前设 transport.type 为 openai-compatible，并明确允许外部处理 allowExternalProcessing=true；配置自己的环境变量 EVERLIGHT_API_URL（完整 chat/completions 地址）、EVERLIGHT_API_KEY、EVERLIGHT_MODEL。先确认供应商的隐私、留存和费用规则。默认 embedding.type=lexical，使用本地词项/BM25 关联；若选择兼容向量接口或离线候选向量，参考 converter/README.md，设置实际模型和维度，不能把原话向量冒充候选向量。D9 合同用于分类提示与结果校验。

```sh
node converter/src/cli.mjs prepare --config converter/config.json
node converter/src/cli.mjs calibrate --config converter/config.json
node converter/src/cli.mjs verify --config converter/config.json --mode calibration
```

先检查校准结果；不要逐条检查十万条，但当前仍须真实检查最多 1000 条的校准样本，然后执行（审核人和理由按实际填写）：

```sh
node converter/src/cli.mjs approve-calibration --config converter/config.json --reviewer '实际审核人' --note '实际核对结果'
node converter/src/cli.mjs run --config converter/config.json
node converter/src/cli.mjs verify --config converter/config.json
node converter/src/cli.mjs merge --config converter/config.json
npm run beta:import -- --config converter/config.json --confirm-history --queue
```

`--queue` 自动向核心提交通过合同和基本冲突检查的候选，无需逐条点接受；历史任务、身份、关系、媒体、来源冲突、历史版本冲突或不合合同的候选暂缓，原话不丢。报告分别统计分类状态、排队、暂缓和提交。模型分类结果不等于 AI 独立审核。模拟分类不得批量提交。默认不开启自动 AI 审核。

## C. 已独立批准的历史经历批量提交（实验性）
只有通过独立 AI 审核的、明确日期且非未来的 S04 历史经历，可以在用户明确授权后批量提交。先检查 `bootstrap-report.json` 的候选及分类批次哈希；需要真实宿主独立 AI 审核，不得人工伪造 AI 凭据或投票。当前默认试用环境不自动执行独立 AI 审核，因此没有该审核时不会正式提交。

```sh
npm run beta:import -- --config converter/config.json --confirm-history --queue --commit-approved <报告中的classification_batch>
```

命令通过独立人类审核凭据写入批次授权；核心检查当前摘要、AI 决策及写入回执。无 AI 批准、拒绝或其他库类型不会自动正式提交。重跑不会重复入库。S02/S10 只由系统生成。

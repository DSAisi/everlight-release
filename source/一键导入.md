# Beta 14-A：首次历史导入降成本（专项测试候选）

使用独立试用库，先备份已有数据。人类只需确认数据范围、供应商和预算；AI 负责配置、执行和读取报告。普通原话明文归档，不是夜契；请先排除密钥、私密及未经授权的数据。

## 1. 免费归档
按 README 初始化并启动服务，然后执行：
```sh
npm run beta:easy-import -- "聊天记录.jsonl" --confirm-history --raw-only
```
不调用语言模型或外部向量。支持 JSONL、顶层数组 JSON、TXT、CSV、GZ，最多十万条。不同平台的字段映射见 converter/config.example.json。

## 2. 默认单轮分类与机器准入
```sh
npm run beta:easy-import -- "聊天记录.jsonl" --confirm-history --allow-model
```
--confirm-history 为一次批次授权；--allow-model 为允许配置的语言模型处理数据。先归档 S01，再按上下文分块做一轮语义分类；每个结果验证覆盖和 D9 合同；失败的请求可能重试。无第二轮独立模型复核，也不生成虚假的批准票。符合条件的新历史记录（明确日期的 S04、未验证方法的 S06、明确历史 S08、已过有效期的 S05）经原文匹配、来源、时序、版本、权限、冲突检查后可正式入库。结构化记录不是事实证明；不能仅凭相似度确认身份、关系、当前事实或任务完成。疑难保留原话及候选，未来按需检查。

## 3. 向量辅助分类（可选）
复制 converter/config.example.json 为自己的私有配置，设置 embedding.type=openai-compatible（或 offline-vectors）、model、dimensions、batchSize、revision、maxInputBytes；配置 EVERLIGHT_EMBEDDING_URL（完整 embeddings URL）和 EVERLIGHT_EMBEDDING_KEY，语言模型仍需其单独的 URL/key/model 环境变量。使用本地兼容端点或经授权的外部供应商；百炼等实际接口尚未验收。不要在仓库提交密钥。
```sh
npm run beta:easy-import -- "聊天记录.jsonl" --confirm-history --allow-model --allow-embedding --vector-classify --config ./my-config.json
```
向量在分类前对九种可结构化库的中英文示例原型排序，提供最多三个候选标签给分类模型；S01/S02/S10 不参与分类原型。仍是语言模型批量分类，尚不是向量单独自动写入或按需跳过模型。默认 lexical 为词法检索，不是真正语义 embedding。离线向量需精确匹配模型、维度、版本及文本哈希，覆盖原型、原话和分类后候选；不匹配会失败而非静默混用。向量分类串行执行以保护本进程预算账本。外部向量调用需要额外授权，可能收费。Token 预算为保守估计，向量预算按输入字节，不是账单金额。

## 4. 可选严格复核
追加 --strict-review 恢复 Beta13 校准及独立模型复核路径，可能发生额外模型费用。日常写入与梦境修订的原治理机制不变。

## 5. 验收与重试
查看 trial-beta/imports/<批次指纹>/bootstrap-report.json 和 easy-progress.json。机器准入回执 historical.machine_admission，明确 semantic_review_verified=false。相同文件、配置和新版批次可以继续，复用结果和来源；更改配置或从旧版升级可能重新分类，不保证跨文件去重或跨版本缓存。确认无进程后才清理残留锁。报告中 held/pending 不等于已正式入库；不强制人类逐条复核。当前不支持完整向量免语言模型分类、批次撤回、真实十万条入库成本验收或全部记忆库自动正式提交。production_approved=false。

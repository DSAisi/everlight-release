# Beta 04：历史记忆一次导入

> Beta 09 增量研发预览：梦境宿主邀请与 AI 自选分类见 `做梦与宿主接入.md`。八大内部认知模块继续隔离。未完成其他 P0 和正式发行联调，不作为最终公开发行包。下文 Beta 08 范围约束继续生效。

先按 README 初始化独立试用库、配置自己的测试模型，并启动服务。无需另装转换器，也无需手工逐条分类。

在另一个终端打开本包目录，运行：

```sh
npm run beta:easy-import -- "聊天记录.jsonl" --confirm-history --allow-model
```

`--confirm-history` 表示你一次授权此批历史原话归档及满足条件的历史经历正式提交；`--allow-model` 表示同意将必要历史内容发送至已经配置的模型进行分类、另一次独立复核（默认同一模型），可能产生费用或供应商留存。只导入自己有权处理的非敏感测试数据，排除凭据、私密及未获许可的第三方记录。当前仅支持独立 personal 内测库。无需模型的纯归档命令：

```sh
npm run beta:easy-import -- "聊天记录.jsonl" --confirm-history --raw-only
```

支持 JSONL、顶层数组 JSON、TXT、CSV 和上述格式的 GZ 文件，最多十万条；嵌套平台专用格式需先转换为通用消息格式。默认字段映射见 converter/config.example.json；如不同可复制该文件，修改 fieldMap，然后追加 `--config 路径`。自定义配置模式使用其声明的模型环境变量，而不是自动读取网关配置；Embedding 默认为本地 BM25 关联，如需向量服务可在自定义配置中设置 embedding.type、供应商环境变量、模型、维度，参考 converter/README.md。默认预算为转换器保守估计的 1000 万 Token，不是精确计费或绝对上限。达到预算会停止后续模型工作或保留待审项目。

后台自动执行：准备与校验、S01 原话归档、100 条结构校准（不冒充人工语义验收）、完整语义分类、D9 合同检查、BM25/可选向量关联、候选排队、明确日期的历史经历独立模型复核、已获批准经历自动提交与读回。其他类型可形成候选但不自动正式提交；历史任务、身份、关系、媒体与已知冲突等暂缓。S02/S10 为系统账本，不能从旧原话伪造。未通过审核、缺失证据或失败的项目不视为正式记忆。

命令输出阶段进度。报告位于 trial-beta/imports/<批次指纹>/bootstrap-report.json，分类与关联结果位于该批次 exports/，阶段状态为 easy-progress.json。同一文件和配置可重跑，复用分类结果、原话和正式记忆；改文件或配置可能生成新批次。非正常强杀可能留下 easy.lock/run.lock，必须确认没有导入进程后才可删除旧锁。报告含私人内容或关联线索，不要发送给他人。尚无图形化导入按钮、批次撤回或真实十万条模型入库验收；建议先使用虚构小样本。

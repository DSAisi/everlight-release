# Beta 10 API 接线与调用实例

## 地址、权限、传输

核心默认 18790、面板 18787、聊天网关 18792；实际以 trial.env 和 gateway.local.json 为准。全部回环。核心直连 `/api/v8/...`，人类面板使用 `/api/everlight/v1?route=<URL编码后的逻辑路径>`，宿主照片/夜契走面板直接 `/ui/api/v1/host/...`，不可混用。模型供应商 URL 与长明网关 URL 不同。JSON 请求 content-type application/json；媒体二进制按专用合同。凭据从本机私有文件读取，不进入模型上下文。

| 角色 | 凭据 |
|---|---|
| 核心读取、基础写入 | Authorization: Bearer EVERLIGHT_CORE_TOKEN |
| 受信核心宿主 | 上述 + x-everlight-host-token: EVERLIGHT_SHARED_HOST_TOKEN |
| AI/人类独立审核 | 核心凭据 + 对应 x-everlight-decision-token（AI_DECISION_TOKEN / HUMAN_DECISION_TOKEN）；仅真实授权 |
| 治理管理 | 独立 GOVERNANCE_ADMIN_TOKEN，具体路由按核心合同 |
| 面板 | UI_TOKEN 登录或 Bearer；不使用核心管理密钥 |
| 面板宿主照片、夜契、维护 | EVERLIGHT_HOST_TOKEN，不能用 UI_TOKEN 替代 |
| Connect | EVERLIGHT_CONNECT_TOKEN；受信宿主只读事件和确认接收 |
| 聊天网关 | gateway.local.json 的 gateway_key；不是上游模型密钥 |

## 一段可执行的本机只读探针

在包根目录创建 `local-probe.mjs`（自行维护，不属于发行文件），启动独立服务后运行 `node local-probe.mjs`。只打印健康状态，不回显隐私内容或密钥。

```js
import {readFileSync} from 'node:fs';
import {parseEnv} from 'node:util';
import {EverlightHostAdapter} from './adapters/host-neutral.mjs';
import {connectClient} from './adapters/connect-e12.mjs';
const e=parseEnv(readFileSync('trial-beta/trial.env','utf8'));
const core=new EverlightHostAdapter({baseUrl:e.EVERLIGHT_CORE_URL,token:e.EVERLIGHT_CORE_TOKEN,hostToken:e.EVERLIGHT_SHARED_HOST_TOKEN});
const panel=`http://127.0.0.1:${e.PORT}`;
const connect=connectClient({url:panel,token:e.EVERLIGHT_CONNECT_TOKEN,unified:true});
const route=new URL('/api/everlight/v1',panel);
route.searchParams.set('route','/api/v8/ui/settings');
const r=await fetch(route,{headers:{authorization:'Bearer '+e.EVERLIGHT_UI_TOKEN}});
if(!r.ok)throw Error('settings HTTP '+r.status);
const settings=await r.json();
const m=await connect.discover();
await core.request('GET','/api/v8/status');
console.log({core:'reachable',settings:settings.core.map(({key,available,effective})=>({key,available,effective})),inbox:!!m.inbox});
```

## 照片和夜契：专用面板宿主通道（不是核心 bearer）

照片：`GET/PUT /ui/api/v1/media/settings`（UI，autoEnabled,human_message,ai_generated,tool_capture,ai_bookmarked）。`POST /ui/api/v1/host/evidence`（宿主，id,scope,actor,kind,sourceRef，可选 subject,field,value,effectiveAt）；分别登记实际图像事件及实际 AI 回复事件（kind=assistant_response 或 image_analysis_result、field=visual_input_consumed、value 含图像事件 ID）。`POST /ui/api/v1/host/media/completed` 二进制 body；头 `x-everlight-source-kind`、`x-everlight-source-ref`、`x-everlight-event-id`、`x-everlight-response-event-id`、`x-everlight-response-source-ref`、`x-everlight-ai-description`、`x-everlight-album`，中文头值按 URL 编码；D9 必须有非“未分类”相册。手动照片走 `/media/upload`，source-kind=manual。真实图像/回复缺一不可；不能以说明文字冒充视觉读取。删除、注释、撤回见 media-api.mjs；host/evidence/{id}/revoke JSON reason 会清理关联媒体。严格 D9 不使用旧 host/media/capture。

夜契：人类通过面板设置密码及频道授权，UI `GET/PUT /ui/api/v1/vault/auto`；宿主每轮 `GET /ui/api/v1/host/night/reminder`，头 x-everlight-channel-id、x-everlight-chat-is-private:true。返回 shouldRemind=true 才可在已授权场景使用提示。`POST /ui/api/v1/host/night/evidence`：sourceEventId,sourceRef,channelId,chatIsPrivate,userAuthorized；`POST /ui/api/v1/host/night/capture` 再加 adultAndConsenting、envelope（公钥密封结构，以 vault-api.mjs sealedValid 与 night.js 实际加密实现为准）。不要自创密文格式或发送明文；`POST /ui/api/v1/host/night/revoke`：sourceEventId。夜契不自动注入普通召回。测试先用非敏感合成记录。

## 更新接口

UI GET `/ui/api/v1/updates`、POST `/ui/api/v1/updates/check`、POST `/ui/api/v1/updates/authorize`（repository,version,confirm:true）。宿主以独立 HOST_TOKEN 经统一网关 GET/POST `/ui/api/v1/host/updates`，POST id,state[,backup_id,health_ok,detail]。具体命令及顺序见发行与更新.md。缺少签名、公钥、完整快照、停写或健康检查则不执行。不能把普通提醒当成安装授权。

## 完整路由索引与开发定位

以下为源码机器清单与面板统一网关 allowlist 生成的接口索引，不是对每条接口的真实模型端到端认证。核心 handler 主要位于 `core/server.mjs`（按 METHOD + path 搜索）、`core/connect-e12.mjs`、`core/engine.mjs`；面板位于 `dashboard/server.mjs`、`media-api.mjs`、`vault-api.mjs`。动态参数和请求 body 必须依据相应 handler、机器合同和测试，不猜测未列字段。内部、旧版、未授权路由可能返回 404/410/403，不能为了可用而绕过。每条变更接口先用隔离合成数据检查拒绝、正向、读回和幂等性。

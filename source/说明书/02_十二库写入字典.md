# 十二库严格写入字典（从 WRITE_CONTRACT_D9.json 生成）

当前合同 everlight.write.d9。`template_version` 示例为 `everlight.write.d7`，`contract_version` 为 `everlight.write.d9`；运行时以 /api/v8/write/contracts 为准。以下是实际机器模板，不是模型自由发挥的格式。

## S01 系统账本

原话原样保存，角色、渠道、会话、发生时间由宿主提供；不制造缺失来源。

```json
{
  "writer": "host",
  "route": "POST /api/v8/source",
  "required": [
    "scope",
    "actor",
    "kind",
    "source_ref",
    "body"
  ],
  "optional": [
    "source_id"
  ],
  "rule": "原话原样保存，角色、渠道、会话、发生时间由宿主提供；不制造缺失来源。"
}
```

## S02 系统账本

真实动作自动回执，AI 不可提案或伪造。

```json
{
  "writer": "engine",
  "route": null,
  "rule": "真实动作自动回执，AI 不可提案或伪造。"
}
```

## S10 系统账本

真实检索和请求快照才记账，选中不等于注入。

```json
{
  "writer": "engine",
  "route": "POST /api/v8/recall + POST /api/v8/recall/readback",
  "rule": "真实检索和请求快照才记账，选中不等于注入。"
}
```

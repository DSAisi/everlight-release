## 原清单的已知限制

- UI routes use separate /ui/api/v1 gateway and cannot be inferred to be v8 core routes
- Dashboard dynamic routes and methods require host integration verification
- S01/S02/S10 system ledger only
- Minimum payload validator is not recovered v1.4 complete machine template
- Night vault exists in v7 dashboard but is not integrated with v8 canonical store

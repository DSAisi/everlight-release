## 2. 可选：连接自己的 AI
仅测试你有权处理的、非敏感、单人测试数据；网关会向你选择的模型供应商传输请求与选中记忆，供应商可能收费或留存。不要填现役项目或共享客户密钥。先停止 beta:start。

Linux/macOS：`umask 077; cp provider.example.json provider.local.json; chmod 600 provider.local.json`，用本机编辑器填写上游 OpenAI-compatible /v1 基地址、模型 ID 和自己的测试密钥；默认不启用 association_recall。不要将配置发给其他人。

```sh
npm run beta:gateway -- provider.local.json
npm run beta:start
```
在支持自定义 OpenAI-compatible API 的客户端中填 http://127.0.0.1:18792/v1，模型填写配置中的 ID，API Key 使用 `trial-beta/gateway.local.json` 里的 `gateway_key`（不是上游密钥）。不要公开网关端口；只支持本地客户端。网关配置只创建一次，不覆盖原配置；要更换服务，停止后备份并移走旧 gateway.local.json，再配置。删除 provider.local.json 前确认不再需要，避免重复保存密钥。

J12 二次联想试验：在首次配置前将 `association_recall` 改为 true。只用于单人私人 scope、非流式、单候选且无客户端工具/结构化输出的聊天；模型必须支持工具调用。额外模型请求可能计费；关闭时无该新增工具。现有召回为本地关键词/BM25、人物关联及可选插件框架，不是默认深度语义检索；模型调用也不保证主动联想。自动分类与提交默认关闭，因此网关捕获原话不等于已经生成并审核规范记忆。严禁把私人和客户数据混在一个 scope 中。
